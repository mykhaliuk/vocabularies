Design receipt · type migration

Hanken Grotesk → Rubik

One token changed: --font-sans. The reason is coverage — Hanken has no everyday Cyrillic (U+0400–045F), so any Ukrainian word inside any locale fell back to a system face mid-line. For a dictionary of how people actually talk, that's the content. Rubik covers cyrillic + cyrillic-ext with an italic at every weight. Caveat stays; it always had Cyrillic.

The three calls the brief asked for

Q1 · does the type scale port straight
Yes — unchanged

Measured at 100px: cap heights are near-identical (70.0 vs 69.7), x-height is +5.5%, advance +1.7%. Small text reads a touch larger without growing lines or layouts — for 12–14px meta, chips and nav labels that's a legibility gain, not a defect. No step changes.

Q2 · the headword ratio
--word-scale 1.32 → 1.39

The ratio exists to match Caveat's x-height to the sans around it. Re-derived from measurement: 1.32 × (52.0 / 49.3) = 1.392, pinned at 1.39. The headword keeps exactly the perceived dominance it had; base shrink steps (40/33/27/22/19) untouched.

Q3 · the wordmark
Follows --font-sans, deliberately

The logo is placeholder artwork by the DS's own admission; outlining a placeholder freezes the wrong thing. The SVG's font-family is set to Rubik explicitly. Convert to paths once, when the brand artwork is final.

Watchlist

  • Rubik has a different personality — geometric with softly rounded corners vs Hanken's humanist warmth. At UI sizes the difference is quiet; at display sizes (landing hero, 800 weight) it's visible. Worth one pass over the landing page before calling the brand settled.
  • Offline/PWA fonts — the CSS still loads from the Google Fonts CDN. The self-hosting note in the DS README applies unchanged; the woff2 set to fetch is now Rubik's seven styles + Caveat.
  • Spec mocks — the four spec pages inherit Rubik through the token automatically; hard-coded rendered headword sizes were re-checked (one adjusted in entry-actions-spec).
